# Other Methods

The following installation methods are available for specific use cases beyond the standard POC workflow:

- [VMware vSphere IPI](vmware-install.md) — Installer-Provisioned Infrastructure on VMware vSphere
- [Disconnected: Air-Gapped (Mirror Registry)](disconnected-airgapped.md) — Fully air-gapped environments with no outbound connectivity
- [Disconnected: Pull-Through Cache (Artifactory / Nexus)](disconnected-pull-through.md) — Environments with an artifact repository that has outbound access
- [OpenShift on OpenShift (Hosted Control Planes)](openshift-on-openshift.md) — Nested clusters with control planes running as pods

For the primary POC installation methods, see the [Installation Overview](../index.md).
