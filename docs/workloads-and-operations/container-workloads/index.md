# Example Container Workloads

- [Kafka Cluster with Strimzi](./kafka-strimzi.md) — Deploy Apache Kafka using the Strimzi operator
- [Source-to-Image (S2I) Build](./s2i-build.md) — Deploy applications directly from Git with no Containerfile
- [PostgreSQL with Persistent Storage](./postgresql.md) — Validate CSI storage with a stateful database workload using a Red Hat Hardened Image
- [PVC Read-Back Test](./pvc-readback.md) — Validate CSI storage with a write-then-read PVC test
- [Bookinfo (Service Mesh)](./bookinfo.md) — Multi-service demo for traffic management and mTLS with Istio ambient mode
