# Operational Validation

These exercises validate that the cluster handles failure scenarios and data protection correctly.

- **[VM Failover Test](./vm-failover.md)** — Validate node-loss recovery within the 120-second target
- **[Container Failover Test](./container-failover.md)** — Validate container rescheduling on node failure
- **[VM Backup and Restore](./vm-backup-restore.md)** — Exercise OADP with the kubevirt plugin
